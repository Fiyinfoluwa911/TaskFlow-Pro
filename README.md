# TaskFlow Pro

TaskFlow Pro is a modern task management and productivity web application built with HTML, CSS, and JavaScript.

## Features

- User authentication
- Task management
- Dashboard
- Calendar
- Productivity analytics
- Dark mode
- Responsive design

## Technologies

- HTML5
- CSS3
- JavaScript (ES6)
- Font Awesome
- Google Fonts

## Future Improvements

- Node.js backend
- MongoDB database
- JWT authentication
- Email notifications
